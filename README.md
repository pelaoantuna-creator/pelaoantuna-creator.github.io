# EF Adaptada

Juego de Educación Física Adaptada, como app web para iPad.

Abre https://pelaoantuna-creator.github.io en Safari → Compartir → «Añadir a pantalla de inicio».
Los datos (clases, alumnado, fotos, sesiones) se guardan solo en el dispositivo.
Usa «Copia de seguridad», al final de la portada, para guardarlos en Archivos o en iCloud Drive.
